Figma Smart Animate & Component Variants

Interactive Component States & Motion System

Created for the design agency to effortlessly construct interactive components and Smart Animate prototypes in Figma. Capture this page directly into Figma via html.to.design to import all component variant sets with their resting, hover, active, and expanded states side-by-side.

1. Import to Figma Run html.to.design on this page URL (http://localhost:8765/figma-components.html).
2. Combine as Variants Select each row of component frames in Figma → click "Combine as variants" in the right sidebar.
3. Add Interactions Switch to Figma's Prototype tab → drag connection from Default to Hover with While Hovering → Smart Animate.
