Step-by-step workflow for Figma
  1. Install the html.to.design extension in Chrome and its companion plugin in Figma (by divRIOTS).
  2. Serve this project locally via python3 -m http.server 8765 and open http://localhost:8765/figma-import.html in Chrome (local web server required; file:// URLs cannot be captured).
  3. Click any viewport link below. All frames open in static=1 capture mode (elements render immediately at full opacity without waiting for scroll reveals or CSS transitions).
  4. Trigger the html.to.design Chrome extension, confirm the viewport width (1440, 820, or 390), and click Import to Figma.
  5. For interactive animations, import figma-components.html → select rows → Combine as Variants → connect with While Hovering → Smart Animate.
  6. Fonts (Fraunces and Inter) are native to Google Fonts and load automatically in Figma.
