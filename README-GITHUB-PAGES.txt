INPHA — GitHub Pages static design preview

This package is already laid out for a GitHub Pages source at repository ROOT.
Do NOT upload the outer ZIP as one file; unzip it and upload all its inner files/folders to the repository root.

Steps:
1. Create a PUBLIC repository on GitHub, e.g. inpha-design-preview.
2. Add all files from this ZIP's root to the repository root, including index.html, inpha.css, data.js, hifi.js, and assets/.
3. Under Settings > Pages, select Deploy from a branch > main > / (root) > Save.
4. The project URL will typically be: https://USERNAME.github.io/inpha-design-preview/
5. Share the full website design REVIEW link above with the agency.
6. Single-page views: ?p=home&w=1440 ; ?p=school&w=1440 ; ?p=student&w=390 ; ?p=tech&w=1440
7. The design deck: /deck.html (HTML presentation).

NOTE: This is a UI/UX design concept, NOT a complete production website. Several buttons/nav links are placeholders (href='#'); forms do not submit; WhatsApp/call actions are not configured. Text and imagery placeholders require client-approved assets and content.

Any repository/public Pages site may expose the designs to the public. Confirm agency permission before publishing confidential materials.
